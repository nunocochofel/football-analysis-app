# LINHA — Análise de Vídeo de Futebol

Este repositório contém apenas os **instaladores** da LINHA (secção *Releases*). O código-fonte
não é público.

## Descarregar

| Plataforma | Como instalar |
|---|---|
| 🪟 **Windows** | [Descarregar o instalador mais recente](https://github.com/nunocochofel/football-analysis-app/releases/latest) (ficheiro `.exe`) |
| 🍎 **macOS** | [Descarregar o instalador mais recente](https://github.com/nunocochofel/football-analysis-app/releases/latest) (ficheiro `.dmg`) |
| 📱 **iPhone / iPad / Android** | Abrir **https://linha.pages.dev** e instalar a partir do browser ("Adicionar ao Ecrã Principal" no Safari, "Instalar aplicação" no Chrome) |

A versão de computador atualiza-se sozinha a partir daqui.
