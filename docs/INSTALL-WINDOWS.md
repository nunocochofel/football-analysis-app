# Instalação no Windows

## Requisitos

- Windows 10 ou 11 (64-bit).
- Cerca de 500 MB de espaço livre em disco.

## Método de instalação

Instalador nativo `.exe` (NSIS), descarregado diretamente do GitHub Releases.

## Passo 1

Vai a [github.com/nunocochofel/football-analysis-app/releases/latest](https://github.com/nunocochofel/football-analysis-app/releases/latest)
e descarrega o ficheiro `football-analysis-app-setup-X.X.X.exe`.

## Passo 2

Corre o instalador. Podes escolher a pasta de instalação (não é "one-click").

## Passo 3

Segue o assistente até ao fim. É criado um atalho no Ambiente de Trabalho e no Menu Iniciar.

## Primeiro arranque

Abre a app pelo atalho criado. Não é necessária conta nem ligação à internet para usar a app —
só é usada internet para verificar atualizações.

## Permissões

O Windows pode mostrar um aviso do SmartScreen ("Windows protegeu o seu PC") em instaladores não
assinados com um certificado reconhecido. Se aparecer, clica em "Mais informações" → "Executar
mesmo assim".

## Importar vídeos

Botão "Carregar vídeo" na barra de ferramentas — abre o explorador de ficheiros nativo do Windows.

## Utilização fullscreen

Botão de ecrã inteiro (⛶) junto aos controlos de vídeo. Os atalhos de teclado continuam
disponíveis em fullscreen. ESC sai do ecrã inteiro.

## Problemas comuns

- **A app não abre**: confirma que és 64-bit (Definições → Sistema → Acerca de).
- **Vídeo não reproduz**: formatos comuns (MP4/H.264) funcionam sempre; formatos raros podem
  precisar de conversão — a app avisa e sugere.

## Como atualizar

A app verifica atualizações automaticamente e avisa quando há uma nova versão disponível.
